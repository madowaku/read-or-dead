# READ OR DEAD

読めたら撃て。撃ったら渡せ。

文字やシルエットを見て答え、正解した人が画像を一発ずつ撃って消していく認識リレーゲームです。誰かが読めなくなったら終了。最後に、消えた絵が元に戻っていく逆再生リプレイを動画か画像で共有できます。

スマートフォンの縦画面向けの Web アプリで、インストールは不要です。

## 現在の範囲（Phase 1：ゲーム性の検証）

- 1 台の端末を回して遊ぶローカルモード
- 文字 10 問・シルエット 10 問（おまかせ出題）と、自作の文字問題
- 回答は 1 人 1 回。正解したら 1 発だけ撃てる。不正解・ギブアップで終了
- 終了画面（挑戦した人数、読めた人数、撃った数、最後の回答、答え）
- 9:16 の逆再生リプレイ（0.5× / 1× / 2×）
- 動画（MP4、非対応なら WebM）で共有。動画を作れない端末では画像で保存

Phase 2（非同期 URL リレー）は未実装です。データの形（Chain / Shot / Turn）は Phase 2 でサーバーに移せるようにそろえてあります。

## 開発

```bash
npm install
npm run dev      # http://localhost:5173（同じ LAN のスマホからも開ける）
npm test         # 回答の正規化・リレー進行・リプレイの時間割のテスト
npm run build    # dist/ に静的ファイルを出力
```

`main` への push で GitHub Pages にデプロイされます（リポジトリの Settings → Pages で Source を「GitHub Actions」にしておく必要があります）。

## 構成

| 場所 | 役割 |
| --- | --- |
| `src/game/relay.ts` | リレー進行。参加権・回答判定・1 発射撃・終了を管理し、正解情報は終了後にしか出さない |
| `src/game/normalize.ts` | 回答の正規化（ひらがな／カタカナ、全角／半角、大文字／小文字、記号） |
| `src/game/render.ts` | 問題画像の生成（1024×1024）と弾痕（透明な円）の適用 |
| `src/game/questions.ts` | 問題バンク |
| `src/replay/` | 逆再生の時間割、9:16 フレームの描画、録画、共有・保存 |
| `src/app.ts` | 画面遷移 |
| `assets-src/silhouettes/` | シルエット画像の元データ（Codex の画像生成で作成）。公開用は答えが分からないよう番号名で `public/questions/silhouette/` に置く |

### 仕様上の決めごと

- 弾痕の座標は 0〜1 の正規化値、半径は画像の幅に対する比率（`SHOT_RADIUS = 0.08`）で保存する。画面サイズが違っても同じ位置に穴が開く
- 描画は常に「元画像 → 弾痕を順に透明化」で作り直す。逆再生は弾痕を後ろから外していくだけなので、最後は元画像と完全に一致する
- 文字問題は同梱フォント（Dela Gothic One）の読み込みを待ってから描く。端末ごとのフォント差で画像が変わらないようにするため
- 進行中のゲームは端末の localStorage に保存し、タブが破棄されても続きから遊べる

## 検証したいこと

1. 撃つ位置を選ぶこと自体が楽しいか
2. 認識不能になるまで適切なターン数が続くか（穴の大きさ `SHOT_RADIUS` で調整）
3. 読めた・読めなかったの境目に納得感があるか
4. 逆再生リプレイを他人に見せたくなるか
